# Fruit Jam

**Fruit Jam** is a quirky, narrative-driven adventure game created in just **72 hours** for a fast-paced Game Jam using the **Godot Engine**. Step into the peel of a determined banana as he embarks on a bizarre, humorous journey to uncover the mystery behind his missing wife. Blending witty storytelling, absurd characters, and a touch of tropical noir, *Fruit Jam* is a short but memorable experience born from creativity under pressure.
